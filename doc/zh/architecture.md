# 架构

[文档目录](README.md) · [English](../en/architecture.md)

## 职责划分

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 启动与路由 | `src/main.ts`、`src/router.ts` | 注册平台能力、偏好、懒加载 hash 路由、移动端返回来源 |
| 传输 | `src/core/api/` | 独立后端客户端、请求错误、幂等键、SSE 解码 |
| 状态 | `src/core/state/` | 会话列表、持久历史、流式交接、浏览器偏好、全局统计 |
| 配置 | `src/core/config-editor.ts`、`src/core/provider-catalog.ts` | 带版本的草稿、明确修改项、模型发现 |
| 业务界面 | `src/features/` | 会话、设置、统计、诊断 |
| 公共 UI | `src/ui/` | 弹窗、选择器、焦点、层级、动画、Markdown、通知 |
| 宿主能力 | `src/platform/` | 剪贴板、文件、存储、通知、安装、屏幕唤醒 |
| 托管 | `serve.mjs` | 静态资源和两个独立的流式反向代理 |

Core 不依赖 DOM，使用 Vue 响应式状态和平台注册表。DOM 测量、图表实例、焦点及动画由 UI 层管理。配置编辑器有明确的客户端归属，通用接口封装不另建一份配置状态。

平台注册表会冻结适配器接口。安装提示、唤醒锁等可变状态保存在适配器模块内部，不放在注册对象的可写属性上。

## 会话生命周期

`chatSlice` 用 epoch 管理当前会话。切换或重新打开时，使旧任务失效并中止请求。持久历史使用有界 keyset 分页；搜索只加载目标序号附近的数据，不扫描整个对话。TanStack Virtual 限制实际渲染的历史和会话列表行数。

流式文本是临时状态。每次 `response_start` 和重试都会重置单次请求缓冲。后端保存 Assistant Entry 后发送 `response_complete.entry_id`；当前端持久历史中出现该 ID，就清除对应的临时回显。一次模型响应结束并不意味着 agent run 结束，后面可能还有工具和新的模型请求。最终状态由持久历史和运行状态共同确认。

`/sync/events` 是控制面同步流，负责资源投影失效和删除通知，与模型 Token 流分离。重连后重新读取权威投影；旧异步回调不能覆盖新选中的会话。统计页面离开时也会中止尚未完成的读取。

## 展示与资源管理

会话切换只淡入淡出变化的内容，尽量保留输入区和列表。子面板管理自己的焦点、位置和开关动画。思考区有高度上限、内部滚动及两端渐变；运行中保持可见的动态状态提示。草稿按会话隔离，发送期间切换页面也不会把附件上传到新会话。

图表共用数据归一化、时间范围查询和画布生命周期。后端负责用量及计时。热力图固定七行，按可用宽度计算列数，再请求对应桶时长。TPS 拟合属于展示，不会制造额外采样记录。

## 需要保持的边界

- 提供商调用和配置归 `wish-providerd`，会话和运行管理归 `wishd`。
- 用户模型覆盖值持久保存；上游目录数据只展示，明确编辑后才写入配置。
- 全局用量在会话删除后仍保留；存储数量反映实际存在的资源。
- 全局统计不能退回到扫描各个会话记录。
- Web 未使用的接口不等于后端死代码，CLI 可能仍需要它。

接口协同和验证见[接口契约](api-contract.md)及[开发指南](development.md)。
