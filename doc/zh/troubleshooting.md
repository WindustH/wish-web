# 故障排查

[文档目录](README.md)

分别检查 WebUI 的 /healthz、wish 的 /health，以及代理后的 /api/version。421 表示 Host 不在 ALLOWED_HOSTS 中；401 表示代理令牌与后端不匹配；409 通常表示会话仍在执行或配置版本冲突，应等待中断收尾或重新载入。

模型请求失败时核对协议、Base URL、请求路径以及后端环境变量。模型目录接口不是必需项，手动配置的模型仍可使用。SSE 断线会协调状态，不会重新发起模型请求。异常退出留下的未完成状态需要检查，服务不会盲目重试工具副作用。

部署后刷新页面，若提示新版本已就绪，点击“立即更新”。可运行浏览器自检和只读 API 自检，区分旧 PWA 缓存与后端故障。
