# 故障排查

[文档目录](README.md) · [English](../en/troubleshooting.md)

| 现象 | 检查项 |
| --- | --- |
| Web 无法启动 | 是否构建了 `dist/index.html`，以及 Node 版本、端口和服务日志 |
| HTTP 421 | 将实际访问的 `主机:端口` 加入 `ALLOWED_HOSTS` |
| 写操作返回 HTTP 403 | 检查 Origin、同源代理和后端认证 |
| 会话正常但提供商列表失败 | 检查 `/providerd-api` 的地址、令牌和提供商后端健康状态 |
| 会话请求失败 | 检查 `/wishd-api/health/ready`、网络及运行日志 |
| 失效会话链接自动跳转 | 正常行为：已删除或不存在的会话返回会话入口 |
| 上游模型参数留空 | 上游和协议未提供该值，留空不代表有隐藏默认值 |
| 新模型选择未改变旧会话 | 正常行为：已有会话保留自己的模型选择 |
| Run 中断或失败 | 查看运行错误和工具历史，区分传输重试与已完成工具执行 |
| 曲线与原始点不同 | TPS 曲线经过拟合；数据表保留实际采样值 |
| 发布后仍看到旧资源 | 应用 PWA 更新，不需要清空后端数据 |
| 剪贴板、安装或唤醒不可用 | 检查安全上下文、浏览器支持和权限 |

`/selftest` 提供浏览器 API 诊断，不是生产遥测来源。排查时记录失败请求的状态、code 及相关会话/run ID，不公开凭据和完整配置。浏览器错误、传输故障和后端验证错误应保持可区分。
