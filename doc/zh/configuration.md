# 配置与日常使用

[文档目录](README.md) · [English](../en/configuration.md)

## 浏览器偏好

主题（跟随系统、浅色、深色）、界面语言、Enter 发送、失败通知和屏幕唤醒属于浏览器偏好，不修改后端 TOML。语言使用下拉列表，便于扩展。屏幕唤醒需要浏览器支持，页面隐藏时可能被浏览器释放。

桌面设置使用紧凑弹窗，移动端使用二级页面和底部标签。窄屏将说明收进信息提示。提供商和模型子编辑器保留父界面；固定少量选项可使用胶囊控件，可扩展目录使用搜索选择器。移动端搜索选择器不自动唤起键盘。

## 后端配置

Wishd 和提供商配置各自拥有带 revision 的草稿。先读取可编辑文档，再生成有序 JSON Patch、预览验证和重启要求，最后携带原 revision 保存。并发冲突需要重新读取并检查修改。未编辑的密钥保留原值或环境变量引用；包含密钥的草稿只在页面内存中保存。

提供商预设提供默认配置，并在支持时查询上游模型列表。模型表单中的值可以来自用户覆盖、上游目录或协议默认值；无法确定的字段留空。保存时仅写入明确编辑的字段，不将展示的上游数据固化为覆盖值。

代理使用统一配置：是否启用、环境变量模式或手动 URL。每个提供商只有启用或禁用代理的选择。图片下载遵循共享设置，不再有代理策略列表或独立的图片代理选择。

## 会话与附件

新会话采用选定或默认的提供商、模型和推理强度；已有会话保留自己的选择，直到明确修改。移动端对话根据来源返回主页面或全部会话页面。失效地址会被会话入口替换，不滞留在浏览器返回路径中。

图片按钮选择图片，附件按钮选择文件；发送前完成上传。支持图片的模型可直接接收图片内容，文件附件则以经过验证的本地路径供工具处理。附带图片路径不代表需要再次读取同一张图来确认。

Markdown 禁用原始 HTML 并经过净化；外部链接携带 `noopener noreferrer` 在新标签页打开，当前页面不跳转。代码块支持复制。停止对话使用后端已经持久记录的停止操作，在页面上以红色提示。

## 统计

全局图表使用全局持久化用量，包括已删除会话的贡献；单会话统计仍归各自会话。输入、输出和缓存读取标记 Token 单位；缓存命中率为缓存读取输入 Token 除以总输入 Token。缺失遥测不会被替换为虚构采样。

时间范围支持一天、一周、一个月、三个月、一年和自定义日期。热力图固定七行且格子为正方形，按范围和可用列数计算格子时长。时间戳归属请求，不表示单个 Token 的生成时间。TPS 为有效计时样本的总输出除以总生成时长；拟合线使用相同均值，并叠加标准差为显示范围七分之一的高斯偏差。饼图可能放大小份额或合并小项来改善可读性，但标签保留实际数量和比例；仅一种模型时不显示饼图。
