# 配置

[文档目录](README.md)

设置页通过 `/api/config` 读取和保存 `{revision,config}`。提供方及默认会话配置可热更新，进行中的调用继续使用原客户端。版本冲突返回 409，需要明确重新载入。

提供方配置包括协议、Base URL、路径、认证、密钥环境变量、模型目录、计数及上游压缩协议。模型 ID 可手动配置；完整 JSON 编辑器支持模型属性和请求头。敏感请求头读取时隐藏，未改动的隐藏值在保存时保留。API 密钥使用后端进程中的环境变量，不返回浏览器。

默认会话配置包含模型、思考强度、输出上限、工作目录、工具、流式输出、固定提示词及压缩预算，仅影响新建会话。现有会话保留自己的配置。监听地址、数据目录和访问令牌变量属于启动参数，修改配置文件后需要重启；更改环境变量同样需要重启。

界面偏好和草稿保存在浏览器中，与后端配置分开。
