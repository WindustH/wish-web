# 2026-11-15 前端审计核验与修复

核验基于 `wish-web` 的 `6027f08`，并对照当前 `wish-core` 契约和 `wish-test`。
报告中的确定性故障、可复现的状态丢失和局部性能问题优先修复；架构演进建议与已有机制分别判断。
所有新增回归均放在 `wish-test`，前端仓库不存放测试。

## 已修复

| 范围 | 核验结果与处理 |
| --- | --- |
| 启动与文件夹 | `sessionsSlice` 的模块求值确实早于平台注册。改成注册后显式 `sessions.hydrate()`，恢复 `list.folder`。 |
| 缓存清理 | IndexedDB 清理此前只等打开数据库，未等事务提交。浏览器缓存下沉到平台适配器，写入和清理均在事务完成后返回；连接切换等清理完成再导航，并拒绝迟到的读取与写入。保留原数据库名称，退出时也能清理升级前的数据。 |
| 缓存初始化 | 数据库打开失败后允许重试，不再永久记住失败结果；事务中止向调用者报告。 |
| 偏好分层 | 字号状态不再直接修改 DOM；由启动入口订阅字号并同步样式。移动端偏好守卫补齐原图质量、字号的脏状态与放弃恢复。 |
| 快捷键 | 设置入口和左右侧栏的提示、`aria-keyshortcuts` 使用实际配置；清空绑定会移除旧提示。桌面的快捷键页不再出现服务端配置保存栏。 |

| 侧栏状态 | 库、后台任务与信息、设置一致，首次打开后保持挂载；切换面板不会销毁代码、PDF、媒体预览实例。隐藏面板仍停用轮询。只有当前面板持有 `session-sidebar` ID。 |
| 平板窄窗口 | 按工作区剩余宽度决定停靠或浮层，不仅看屏幕宽度。剩余不足 800px 时右栏以抽屉覆盖；停靠时为正文保留至少 480px。手机原有全屏面板行为保留。 |
| 移动端返回 | 会话列表多选注册返回层；Back 先退出多选。`SessionPanelModal` 的侧栏分支遵守 `backLayer` 参数，调用方显式保留手机侧栏返回。 |

| 粘贴文本 | 编辑使用异步摘要；LAN HTTP 的 SHA-256 回退分块让出主线程，不再复制整份输入进行填充。较新的编辑、移除附件或切换会话会取消旧工作；发送等待尚未完成的编辑。 |

| 流式渲染 | BTW 与主对话共享文本合并调度：短文本按帧、长文本按 200ms 合并，结束或中止时刷新最后内容。 |
| 列表计算 | 默认模型选择的能力查找改为 Map；用量表与问题倒计时复用格式化器。调试设置按需加载。 |

| 表单 | 搜索服务地址在输入时同步草稿，媒体服务地址去除外围空白并规范空值；技能详情使用移动端整页弹窗。 |

## 报告需要纠正或已有保护的部分

- **Reka 补丁并未漏装。** `pnpm-workspace.yaml` 和 lockfile 已声明补丁；真正需要清理的是重复的 package 配置。
- **Firefox 数学样式不能按报告直接删除。** 空参数的 `@-moz-document url-prefix()` 属于保留的兼容例外，`-moz-appearance` CSS 别名也仍受支持；安装的 Temml 样式同样使用它们。参见 [MDN @document](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@document) 和 [Mozilla CSS 扩展说明](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Mozilla_extensions)。这不等于所有 MathML 引擎差异已经消除。
- **库的引用定位已有恢复仲裁。** `selectBlob` 同步更新保存的选中 ID；加载恢复只在该 ID 仍等于恢复快照、会话未改变且请求未释放时写入，`opening` 又防止旧定位请求覆盖新请求。没有据此重写整个库。
- **技能搜索的 Escape 顺序有明确目的。** 先恢复焦点，再关闭结果；弹层已经阻止默认的关闭后自动聚焦。没有发现报告所称的必然竞态，保留这一顺序。
- **缩略图编码回退不是 MIME 契约破坏。** 预览缓存保留浏览器实际返回的 Blob，并以对象 URL 展示；没有强行把 PNG 回退标作 WebP。是否改 JPEG 还涉及透明背景与画质，不做统一替换。
- **触摸按钮对不可取消的 touchend 没有主动补发 click。** 不能直接用 Chromium 专属属性推导出 WebKit 必然重复触发；保留已验证的触摸抑制逻辑。
- **错误文案辅助函数不完全等价。** `InfoPane` 使用本地化的 `describeError(...).message`，不能机械换成原始 `errorDetail` 丢失翻译。
- **日期天数不应按实际毫秒除以 24 小时。** 跨 DST 的日历日可以是 23/25 小时。保留日历日计数，修的是曲线边界与后端固定偏移的不同语义。

## 未扩大到这次修复的工作

- `ChatPane`、`SessionLibrary`、API 定义及消息判别类型的全面拆分属于后续模块演进。这里已收拢缓存平台边界、搜索聚焦和流式调度，未为了文件行数一次重写这些功能。
- 调试记录目前仍有浏览器专用的逐标签页存储；迁移到原生存储需要保留会话隔离、旧记录迁移和显式水合契约，不能简单替换成持久化的 `platform.storage`。
- 列表当前支持横向滑动直接进入拖动，非 passive 的移动监听服务于这项行为。直接等长按后再注册会改变现有手势；应与拖动入口设计一起调整。
- 未把所有手机断点整体改成三档。保留竖屏阅读宽度和现有页面/返回栈，在已确认的双栏挤压处增加工作区自适应。
- Tauri HTTP/SSE 代理、原生下载、OAuth 外部浏览器和退出语义需要真实外壳实现。不能通过放宽无令牌 CORS/Origin 守卫来实现“就绪”。现有同源访问与访问令牌约束保留。
- 未宣称真机 iOS、Gecko 或 Tauri 已通过认证。浏览器回归运行于 Chromium；已有键盘视口测试模拟 visualViewport 事件，不能替代真机软键盘与 IME 验证。
