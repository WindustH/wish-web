# 配置

[文档目录](README.md) · [English](../en/configuration.md)

设置中的“服务与会话”和“提供商”两部分通过 `GET` / `PUT /api/config` 编辑 Wish 服务端的配置文件，“界面”只影响当前浏览器。服务端每个字段（包括界面上没有的）的说明见服务端的[配置参考](https://github.com/WindustH/wish-core/blob/master/docs/configuration.md)。

## 保存

- 修改在保存前都只是草稿，点击对话框底部的“保存”才会生效（手机上在离开页面时保存）；“放弃修改”会恢复为已保存的配置。带着未保存的修改关闭时会先询问：“保存并返回”“放弃修改”或“继续编辑”。
- 保存后，修改从下一次操作开始生效，不需要重启服务端；已经在进行中的调用继续使用原来的配置（“已保存并生效。正在运行的调用继续使用原配置。”）。
- 服务端返回的密钥等敏感值显示为 `<redacted>`，输入框提示“已配置，留空保留”，不改动就会保留原值。API 密钥、凭据、请求头的值、OAuth 令牌和代理密码都是如此。
- 如果在你打开设置之后，配置又被别处保存过（服务端返回 `409`），Wish 会读取最新配置，只把你改过的字段重新套用上去，然后再保存一次；双方改了同一个字段时，以你的修改为准。这时会提示“配置已更新；已合并本地修改并保存。”
- `listen`、`data_dir` 和 `bearer_token_env` 只能在配置文件里修改，改完需要重启服务端。

## 服务与会话

这里的设置是之后新建会话的默认值，已有会话保留各自的配置。只想调整某一个会话时，请使用它的“会话设置”（见[使用指南](user-guide.md#会话设置)）。

| 设置 | 服务端字段 | 说明 |
| --- | --- | --- |
| “默认模型” | `defaults.provider`、`defaults.model` | 在起始页用其他模型开始对话时也会更新这两项。模型必须在提供商那里存在：要么已配置，要么出现在它的模型目录里。 |
| “默认思考强度” | `defaults.reasoning.effort` | 选“上游默认”表示不设置。 |
| “工作目录” | `defaults.cwd` | 服务器上的绝对路径，也是起始页工作目录的初始值。 |
| “固定提示词” | `defaults.instructions` | 放在每个新会话的开头。 |
| “上下文压缩”：“触发压缩的 Token 数”“压缩后的目标 Token 数”“触发分段摘要的 Token 阈值” | `defaults.compaction.trigger_tokens`、`.target_tokens`、`.segment_tokens` | 只有配置文件里存在 `defaults.compaction` 时才会显示这一组。 |
| “Shell”：“程序”“启动参数” | `shell.program`、`shell.args` | 见下文。 |

**Shell。**“程序”可以选“系统默认”、服务器上找到的某个 Shell，或“自定义路径…”（可执行文件的绝对路径）。“启动参数”放在命令之前，留空时按 Shell 类型自动选择；“执行方式”会预览最终的启动命令。保存后，所有跟随全局设置的会话（包括已经打开的）都会从下一条命令开始使用新的 Shell；单独设置了 Shell 的会话不受影响。

界面上没有的默认项：`defaults.shell`（新会话是否带 Shell 工具）、`defaults.stream` 和 `defaults.max_output_tokens`。如果模型设置了“最大输出 Token”，新会话会以它作为输出上限。

## 提供商

“模型提供商”列出所有提供商及其名称、ID、预设和启用状态。“添加提供商”可以按提供商、地区或套餐搜索内置预设，也可以添加“自定义提供商”。提供商 ID 就是 `providers` 下的键名（预设 ID 或 `custom`，重名时依次加上 `-2`、`-3`……）。默认模型所属的提供商不能删除，需要先换一个默认模型。

### 编辑提供商

| 设置 | `providers.<id>` 中的字段 | 说明 |
| --- | --- | --- |
| “显示名称” | `display_name` | 默认使用预设的品牌名，没有预设时用 ID。 |
| “启用此提供商” | `enabled` | 停用后，模型选择器里不再出现它的模型。 |
| “协议” | `protocol` | 对预设提供商切换协议时，会一并载入该协议对应的地址、路径、认证方式和模型目录设置。 |
| “使用代理” | `proxy_enabled` | 关闭后，这个提供商始终直连。 |
| “服务地址”“请求路径” | `base_url`、`path` | |
| “认证方式” | `auth` | “无需认证”“Bearer token”“Anthropic API Key”“Google API Key”或“AWS SigV4”。 |
| “API Key” | `api_key` 或 `api_key_env` | 直接填写密钥，或写 `${NAME}`，从服务端进程的环境变量 `NAME` 中读取。 |
| 预设要求的凭据（工作空间 ID、账户 ID；SigV4 需要区域、访问密钥 ID、访问密钥和会话令牌） | `credentials`、`credentials_env` | 同样可以填值或写 `${NAME}`。 |
| “高级设置”：“模型列表协议”“模型列表地址”“模型列表路径” | `model_list`、`model_list_base_url`、`model_list_path` | 从哪里读取提供商的模型列表。可选：不配置时，已配置的模型照样能用。 |
| “Token 计数协议” | `token_count` | 可选，由提供商计算 Token。 |
| “上游压缩协议” | `compaction` | 可选，由提供商执行上下文压缩。 |
| “完整配置 JSON” | 整个提供商对象 | 只有在这里才能编辑 `headers`。桌面端可以用“应用到表单”把它写回草稿。 |

`${NAME}` 引用的环境变量由 Wish 服务端读取，与浏览器无关；修改环境变量后需要重启服务端进程。

### 通过 ChatGPT 登录

用 OpenAI Codex 预设创建的提供商有“通过 ChatGPT 登录”按钮。点击后会先保存尚未保存的设置，然后在新标签页中打开 ChatGPT 授权页面并等待结果。登录成功后，服务端会把令牌写入这个提供商的配置，并在过期前自动刷新。

授权完成后会跳转到服务器本机的 `localhost`。如果你的浏览器不在服务器上，这个页面会打不开：此时把地址栏中的完整链接复制到“粘贴 localhost 授权链接”，再点击“完成登录”。每次登录尝试在十分钟后失效。

### 模型

每个提供商下都有“模型”列表。如果提供商配置了模型目录，“添加模型”会打开“上游模型目录”；新添加的提供商需要先保存。选择“自定义”可以手动输入 ID；目录中没有的 ID 需要打开“确认使用目录外的自定义 ID”。

| 设置 | `providers.<id>.models.<模型>` 中的字段 |
| --- | --- |
| “模型 ID” | 键名 |
| “上下文窗口” | `context_window_tokens`（会话信息中的上下文进度条以它为准） |
| “最大输出 Token” | `max_output_tokens`（新建会话和切换模型时使用） |
| “思考能力” | `supports_reasoning`（“未指定”“支持”“不支持”） |
| “支持的思考等级” | `reasoning_efforts`；留空时沿用预设的等级，“恢复预设”可以还原 |
| “默认思考强度” | `default_reasoning_effort` |
| “支持图片输入” | `input_modalities` 中包含 `image` |
| “完整模型属性 JSON” | 整个模型对象 |
| （确认使用自定义 ID 时） | `custom_model_id: true` |

“应用到配置”只是把模型放进草稿，还需要保存设置才会生效。

### 网络代理

| 设置 | 服务端字段 |
| --- | --- |
| “代理模式” | `proxy.mode`：“系统环境变量”（`environment`）、“手动配置”（`manual`）或“直连”（`direct`） |
| “代理地址” | `proxy.url`，以 `http://` 或 `https://` 开头 |
| “用户名”“密码” | `proxy.username`、`proxy.password` |

“系统环境变量”模式使用服务端进程中的 `HTTPS_PROXY`、`HTTP_PROXY`、`ALL_PROXY` 和 `NO_PROXY`，页面会列出它读到的变量，并隐藏其中的凭据。代理只作用于发往提供商的请求，可以通过各提供商的“使用代理”单独关闭。

## 界面

这些设置立即生效，并且只保存在当前浏览器中。

| 设置 | 作用 |
| --- | --- |
| “主题” | “跟随系统”“浅色”或“深色” |
| “界面语言” | 中文或 English，默认中文 |
| “按 Enter 发送消息”（桌面端） | 开启时 Enter 发送、Shift + Enter 换行；关闭时 Enter 换行、Ctrl/⌘ + Enter 发送 |
| “运行时保持屏幕唤醒”（手机） | 回复进行期间通过 Wake Lock 保持屏幕常亮，需要 HTTPS |
| “运行失败时通知我” | 页面在后台时，每当有会话的运行以失败结束，就弹出系统通知（“运行失败：会话名”，正文是错误信息）。开启时会申请通知权限，需要 HTTPS |
| “安装 Wish” | 在浏览器支持时弹出安装提示 |
| “本地设置”→“清除本地数据” | 见下表 |

## 调试

用于检查应用本身的工具，这里不会保存任何内容。

| 项目 | 作用 |
| --- | --- |
| “连接诊断”→“开始检查” | 在当前页面运行只读检查：核心模块、语言和主题切换、本地存储、服务器版本、会话列表、模型提供商、实时事件流和 Service Worker。检查期间界面语言和主题会短暂切换 |
| “首次使用引导”→“预览” | 预览首次配置流程，不保存任何内容 |

## 浏览器保存的数据

| 位置 | 内容 | “清除本地数据”是否清除 |
| --- | --- | --- |
| `localStorage` 中以 `wish-webui.v1.` 开头的键 | 主题（`theme.mode`）、语言（`locale`）、界面开关（`pref.*`）、会话列表的宽度和收起状态、输入框高度，以及每个会话未发送的文字（`draft.<会话 ID>`） | 是 |
| `localStorage` 中的 `wish-webui.v1.connection` 及 `connection.*` | 直接连接其他服务器时的地址和访问令牌，以及登录页上次填写的地址 | 否；退出时会移除连接信息 |
| `localStorage` 中的 `wish.modelColors` | 图表中分配给各模型的颜色 | 否 |
| `localStorage` 中的 `wish.providerGate.ready` | 这个服务端上次是否已有可用的提供商，用于启动时无需等待即可进入应用 | 否 |
| IndexedDB 数据库 `wish-response-cache` | 下次打开时立即显示的上次数据：统计、用量图表、模型目录、提供商名称 | 是 |
| Service Worker 缓存 | 应用自身的文件和用到过的字体 | 否 |
| 仅在内存中 | 未发送的附件、BTW 对话 | 刷新即丢失 |

已经载入的偏好在刷新页面前仍然有效。服务端的会话和设置不受影响。如需彻底清除，请在浏览器中清除该网站的数据。
