# 使用指南

[文档目录](README.md) · [English](../en/user-guide.md)

Wish Web 是 Wish 服务端的客户端。会话、历史记录、设置和统计数据都保存在服务端，浏览器里只留少量偏好和缓存（见[配置](configuration.md#浏览器保存的数据)）。

## 首次配置

在还没有可用的提供商之前，Wish 不会进入主界面，而是显示“连接你的第一个模型”。一个提供商要算作“可用”，需要已启用、填写了服务地址和请求路径、配好了凭据（无需认证的除外），并且至少有一个模型。

1. 在“提供商”中选择已有配置、内置预设之一，或“自定义 / OpenAI 兼容”。
2. 填写“服务地址”和“API Key”。密钥可以直接填写，也可以写成 `${ENV_NAME}`，让 Wish 服务端从自己进程的环境变量中读取。有些预设还需要额外凭据（例如工作空间 ID、AWS 密钥），会显示对应的输入框。
3. 填写提供商支持的“模型 ID”。
4. “连接选项”里是“提供商 ID”“请求协议”“请求路径”和“认证方式”，选择预设时会自动填好。
5. 点击“保存并开始”：提供商会写入服务端配置，这个模型也会成为新会话的默认模型。

想再看一遍这个引导而不改动任何配置，可以打开设置 →“界面”→“首次使用引导”→“预览”。

## 开始对话

打开应用、在会话列表点击“新建会话”，或按 Ctrl/⌘ + Shift + O，都会进入起始页。输入框上方有两个选项：

- **模型**：打开“选择模型”，列出所有已启用提供商的模型（包括已配置的模型和提供商模型目录中的模型）。能理解图片的模型带有“视觉”标记。
- **推理强度**：可以选模型声明的等级；模型没有声明时提供通用等级；也可以输入任意自定义值，按 Enter 生效。

输入框下方的文件夹按钮用来设置**工作目录**，也就是智能体执行命令时的起始目录。“选择工作目录”可以浏览服务器上的目录（支持“显示隐藏目录”“主目录”“上一级”），也可以直接输入绝对路径。工作目录为空时无法发送，默认值来自设置。

发送第一条消息后会创建会话（以消息的第一行命名）并打开它。这里选的模型和推理强度同时会成为**新会话的默认设置**，效果和在设置里修改一样。如果会话已经创建、但消息没能发出，重试时会沿用这个会话，不会重复创建。

## 对话界面

顶部显示会话名称，以及模型和推理强度两个按钮。右侧是“会话信息与统计”“历史搜索”和“会话设置”（手机上收在“更多”菜单里）。

### 回复与工作过程

- 回复边生成边显示。智能体工作时，状态行会提示它正在做什么，比如“正在思考…”“正在输出回复…”、正在运行的工具名，或“正在压缩上下文”。
- 夹在文字之间的思考和工具调用会折叠成一个“工作过程”块，并显示步数。展开后按顺序列出每一步，点击某一步可以查看详情：执行的命令、状态和退出码、输出（输出过长时会截断，并给出完整输出文件在服务器上的路径）、以 diff 形式展示的文件修改、模型查看过的图片，以及历史检索。
- 智能体在后台运行的命令结束后会回报结果，显示为“后台 Shell 已完成”“后台 Shell 执行失败”或“后台 Shell 已终止”，点击即可查看命令和输出。
- 对话中的提示：红色的“运行失败”表示这一轮失败了；琥珀色的“自动重试中”“上游已暂停”“压缩重试中”“压缩重新分段”“压缩连续未成功”“压缩已恢复”表示服务端正在自行处理问题；“已停止”标记被中断的运行。
- 回复支持 Markdown 和数学公式（TeX），代码块带复制按钮。右键单击消息（触屏上长按）可以“复制消息”，在图片上则是“保存图片”。
- 向上滚动会加载更早的消息，点击“回到最新”可以回到底部。

### 附件与粘贴

- 使用“图片”和“添加附件”按钮，或直接粘贴图片和文件。附件会插入到光标处，发送后就出现在消息的对应位置。
- 图片会以图片形式发给模型；如果模型没有配置图片输入，服务端会改为发送一段说明，附上文件在服务器上的路径。其他文件保存在服务器上，通过路径交给智能体的 Shell 使用。
- 每条消息最多 4 张图片和 16 个文件，每个不超过 20 MB。
- 粘贴超过 128 行或 1024 个字符的文本时，不会直接填进输入框，而是变成一个“Pasted Text N”标签，点击可以查看或修改。发送时这段文本会原样放回消息正文中，不会作为文件上传。
- 未发送的文字会按会话保存在浏览器里。未发送的附件在切换会话时会保留，但刷新页面后会丢失。

### 运行时继续发消息

回复进行中，输入框会提示“发送消息到队列…”，发送按钮变成“发送到队列”。排队的消息显示在输入框上方的“待发送”中，会在这次运行的下一步按顺序送达。

- **调整顺序**：拖动消息（触屏上先长按），或选中后按 ↑ / ↓。
- **“编辑待发消息”**：把消息从队列中取回输入框。
- **“删除待发消息”**：取消这条消息。
- 如果运行恰好在这一刻取走了这条消息，会提示“消息刚被运行中的回复处理,未能取回”。

### 停止运行

点击“停止”（方形按钮）或按 Esc。只要没有打开对话框或菜单，Esc 都可以使用。如果运行停止时队列里还有消息，对话中会提示“运行已停止,队列中还有 N 条消息——发送消息即可恢复”。

### 切换模型和推理强度

任何时候都可以点击模型或推理强度按钮进行修改，运行中也不例外。运行时修改会立即保存，从下一次模型请求开始生效，不会打断当前请求。

### BTW：顺便问一句

输入框工具栏里的“BTW”会打开一个临时对话气泡，可以就当前对话随便提问。模型基于会话截至上一个已完成步骤的上下文作答，不使用任何工具，即使智能体还在运行也能用。追问时会带上之前的 BTW 问答。这些内容不会保存到会话里：回答结束后关闭气泡即清空，也可以点击“清除 BTW 上下文”。“停止回答”可以中止正在生成的回答。

### 历史搜索

“历史搜索”（Ctrl/⌘ + Shift + F）会检索会话的全部历史，包括已经被压缩或从上下文中清空的内容。只要消息中包含搜索的文字就会命中，每次显示 20 条，点击“加载更多结果”查看更多。点击某条结果，对话会滚动到那里。

### 会话信息

“会话信息与统计”包含：

- **上下文**卡片。“当前占用”是上一次模型调用的输入大小，“触发压缩”是压缩阈值，“模型上限”是模型的上下文窗口（取自模型设置或模型目录）。进度条的全长代表模型上限，刻度线标出压缩阈值。

  | 占压缩阈值的比例（未开启压缩时按模型上限计算） | 显示 |
  | --- | --- |
  | 低于 60% | “空间充足” |
  | 60% 到 85% | “接近压缩” |
  | 85% 及以上 | “即将压缩” |
  | 还没有模型调用 | “等待下一次调用” |

- “压缩次数”、“队列”长度、是否正在后台准备待用摘要、客户端的“构建”版本、“创建于”和“更新于”时间，以及“会话指令”。
- 本会话的用量：“模型调用”次数，“输入”“输出”“总计” Token，以及和统计页相同的图表。

### 会话设置

“会话设置”只影响当前会话，新会话仍然使用设置 →“服务与会话”中的默认值。

- **上下文压缩**：用“自动压缩”开关控制是否自动压缩，并设置三个阈值（“触发压缩的 Token 数”“压缩后的目标 Token 数”“触发分段摘要的 Token 阈值”），“使用全局默认值”可以一键恢复。这些修改只能在会话空闲时保存（界面会提示“运行结束后才能保存这项修改”）。
- **“立即压缩”**：马上压缩上下文。前提是这个会话已经配置了压缩。
- **“清空上下文”**：从空白上下文继续，只保留固定提示词。模型将看不到之前的对话，但历史记录仍然保留、可以搜索。操作前会请你确认。
- **Shell**（仅限启用了 Shell 工具的会话）：可以“跟随全局设置”，也可以为这个会话单独指定 Shell 程序和参数。修改从这个会话的下一条命令开始生效，运行中也可以改。

“立即压缩”和“清空上下文”都需要会话处于空闲状态。压缩和 Shell 的修改点击“保存”后生效，“放弃”则撤销修改。

## 会话列表

桌面端的会话列表在左侧，点击边缘的按钮可以收起，拖动边缘可以调整宽度。手机上的首页显示最近 5 个会话，点“查看全部会话”打开完整列表。

- “搜索会话…”按会话名称或 ID 匹配。
- 圆点表示状态：空闲、运行中、排队或压缩中。标签显示在名称旁边。
- ⋮ 菜单中有“重命名”“编辑标签”（最多 16 个，每个不超过 64 个字符，按回车添加）和“删除”。删除会永久清除会话的历史、附件和 Shell 输出，但会保留用量统计。
- 重命名随时可以进行；编辑标签和删除需要会话处于空闲状态。

## 统计

“统计”页汇总所有会话的用量：

- 每日 Token 用量的活动日历，有独立的日期范围选择，可以展开“每日数据”表格，下方注明所用时区。
- 按模型分列的图表，有两种指标。“估算 TPS”展示每个流式请求每秒一次的速度采样：Token 数按收到的字节数 ÷ 4 *估算*，等待和停顿也计入时间；偏离均值 ±2σ 以外的点只是在图上隐藏。“Token 消耗”展示 Token 用量随时间的变化。时间范围可选“一天”“一周”“一个月”“三个月”“一年”或“自定义日期…”，点击图例中的模型可以隐藏它。
- “模型用量”（还可以选“全部”时间）：各模型的占比、“输入”“输出”“缓存命中”和“缓存命中率”，以及“模型 Token 占比”图。
- “服务状态”：Wish 版本、运行中的会话、已保存的会话、运行时长和队列情况。
- “存储”：文件总大小，并按会话数据、资源文件、执行输出和服务数据细分。

页面打开时每 30 秒刷新一次（日历每 5 分钟一次）。下次打开时会先显示上次的数据，再换成最新数据。

## 设置

点击导航栏中的“设置”或按 Ctrl/⌘ + , 打开设置，共分三部分：

- **“服务与会话”**：新会话的默认设置（模型、工作目录、提示词、上下文压缩）和 Shell。
- **“提供商”**：模型提供商及其凭据、模型，以及网络代理。
- **“界面”**：主题、语言、输入方式、通知、安装应用、连接诊断和本地数据。

前两部分修改的是服务端配置，保存后生效；“界面”中的选项立即生效，并且只保存在当前浏览器里。所有选项的说明见[配置](configuration.md)。

## 手机端

窗口宽度小于 900 像素时，Wish 会切换到手机布局：

- 首页就是起始页，下面列出最近的会话；左上角是退出按钮，右上角是统计和设置按钮。
- 对话、会话信息、历史搜索和设置都以全屏页面打开，左上角有返回按钮。
- 回车键用于换行，发送请点击发送按钮。
- 开启“运行时保持屏幕唤醒”（设置 →“界面”）后，回复进行期间屏幕不会熄灭。这需要浏览器支持 Wake Lock，并且通过 HTTPS 访问。

## 安装为应用

在设置 →“界面”→“安装 Wish”中点击“安装”，即可把 Wish 安装为应用。如果浏览器没有弹出安装提示，可以从浏览器菜单选择“安装应用”或“添加到主屏幕”。

安装、离线快速启动和更新提示都要求通过 HTTPS 访问，或者在运行 Wish 的电脑上用 `localhost` 打开（见[部署](deployment.md#通过反向代理启用-https)）。安装后的应用会缓存自身文件以便快速启动，但对话始终需要连接服务端。

部署新版本后会弹出“新版本已就绪”：点击“立即更新”会重新载入新版本，点击“稍后”则暂时继续使用当前版本。Wish 会在你切回页面时（最多每五分钟一次）以及与服务端的连接恢复时检查更新。

## 退出与切换服务器

桌面端导航栏的“设置”按钮上方，以及手机首页的左上角，都有一个退出按钮。确认后，Wish 会断开当前服务器、清除这个浏览器缓存的数据，并显示“连接到 Wish 服务器”页面：

- “服务器地址”留空，即连接提供此页面的服务器，和之前一样。
- 要使用其他 Wish 服务器，填写它的地址（例如 `https://wish.example.com`）和“访问令牌”。之后浏览器会直接连接那台服务器，同一个安装好的应用就能在多台服务器之间切换。

保存之前 Wish 会先检查连接，连不上时会说明原因：地址无法访问、服务器需要令牌、令牌不正确，或者从 HTTPS 页面连接 HTTP 地址。服务器只有在设置了访问令牌时，才接受来自其他网页的连接（见[部署](deployment.md#直接连接其他服务器)）。令牌保存在这个浏览器中，直到退出为止；“清除本地数据”不会清除它。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| Ctrl/⌘ + K | 搜索会话（列表收起时会先展开） |
| Ctrl/⌘ + Shift + F | 在当前会话中进行历史搜索 |
| Ctrl/⌘ + , | 打开设置 |
| Ctrl/⌘ + Shift + O | 新建会话 |
| Enter | 发送（桌面端；Shift + Enter 换行） |
| Ctrl/⌘ + Enter | 关闭“按 Enter 发送消息”后用它发送（此时 Enter 换行） |
| Esc | 停止正在进行的回复 |
| 在待发消息上按 ↑ / ↓ | 上移或下移这条消息 |
| 在输入框的高度调节条上按 ↑ / ↓ / Home / End | 调整输入框高度 |

打开对话框时，前四个快捷键不起作用。
